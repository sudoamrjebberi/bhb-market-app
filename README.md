# BHB Market — بوحلوان إخوان

تطبيق تسيير الفوترة والمخزون، مبني وفق **وثيقة المتطلبات (SRS)** التي أُعدّت من تحليل تطبيق `gestCom` القديم.
يأتي بنسختين تشتركان في نفس الواجهة ونفس منطق الأعمال:

| النسخة | التشغيل | التخزين |
|---|---|---|
| **ويب** | `node server.js` → http://localhost:3000 | ملف JSON ذرّي/معاملاتي (`data/db.json`) |
| **سطح مكتب** | `cd desktop && npm install && npm start` | **Realm** محلي (`bhb-market.realm`) |

> الواجهة عربية RTL بالكامل، متجاوبة (هاتف/لوحي/سطح مكتب)، بأيقونات كبيرة وألوان زرقاء/خضراء هادئة.

---

## 1. التشغيل السريع

```bash
# نسخة الويب (لا تحتاج أي حزمة خارجية — Node 18+ فقط)
cd bhb-market-app
node server.js
# → http://localhost:3000
```

أو على ويندوز: انقر نقراً مزدوجاً على `start-web.cmd` (يشغّل الخادم ويفتح المتصفح)،
وللنسخة المكتبية على `start-desktop.cmd`.

بيانات الدخول الافتراضية:

| المستخدم | كلمة السر | الدور |
|---|---|---|
| `admin` | `Admin@2026` | مدير النظام |
| `comptable` | `Compta@2026` | محاسب |

يُطلب تغيير كلمة السر عند أول دخول (FR-AUTH-09).

## 2. ما الذي أُنجز مقابل وثيقة المتطلبات

### 2.1 المتطلبات الوظيفية

| الوحدة | التغطية |
|---|---|
| **AUTH** | دخول/خروج، جلسات بمدة خمول 30 دقيقة، scrypt، قفل بعد 5 محاولات، تغيير كلمة السر، أدوار وصلاحيات خادمية |
| **DASH** | مؤشرات (مبيعات اليوم/الشهر، الذمم، المواد)، رسم 7 أيام، مواد تحت الحد، أحدث الفواتير، قوائم غير المحصّل |
| **PROD** | CRUD كامل، أسعار HT/TTC، نسب أداء 0/7/13/19، حد تنبيه، حالة جبائية، مزود، بحث وتصفية وترقيم، منع حذف مادة مستعملة |
| **CLI** | CRUD، بيانات جبائية كاملة، منع التكرار بالمعرّف الجبائي، كشف حساب وأرصدة، منع حذف حريف له مستندات |
| **SUP** | CRUD، ربط بالمواد، إحصاء الشراءات، منع الحذف عند الارتباط |
| **INV** | إنشاء/تعديل/عرض، أسطر متعددة، دمج تلقائي للحساب، خصم المخزون، منع البيع بالسالب، دفع كلي/جزئي، إلغاء مع إرجاع المخزون، ترقيم سنوي، بحث وفلترة وتجميع |
| **BON** | إنشاء/تحصيل، تحويل إلى فاتورة **دون خصم المخزون مرتين**، منع التحويل المزدوج، إلغاء مع الإرجاع |
| **PUR** | تسجيل شراء (زيادة مخزون)، تعديل بالفارق، حذف بإنقاص المخزون، مرجع فاتورة المزود |
| **DOC** | فاتورة الحريف، فاتورة المحاسب (تفصيل الأداءات)، الوصل — A4/PDF عبر الطباعة، ترويسة قانونية، مبلغ كتابةً |
| **REP** | المبيعات، الأداءات حسب النسبة، الذمم وأعمار الدين، حركة المخزون، الربحية، الأكثر مبيعاً |
| **SYS** | مستخدمون وأدوار، سجل تدقيق، إعدادات الشركة والضرائب، نسخة احتياطية JSON |

### 2.2 المتطلبات غير الوظيفية (NFR)

- **الأمن**: استعلامات عبر طبقة مستودع بمعاملات (لا دمج لنصوص المستخدم)، scrypt + salt، جلسات HttpOnly/SameSite، **CSRF** على كل الطلبات المعدّلة، تحقق خادمي كامل، رسائل خطأ بلا تفاصيل تقنية، رؤوس أمان.
- **الأداء**: استجابة محلية < 100ms، فهارس منطقية، ترقيم صفحات، تحميل كسول للبيانات.
- **التوطين**: عربية RTL، أرقام/تواريخ محلية، دينار بثلاث منازل، طباعة A4.
- **التوافق/التجاوب**: نقاط قطع 1180/960/640، شريط سفلي للهاتف، أزرار لمس كبيرة.
- **التدقيق**: كل عملية حساسة تُسجَّل (المستخدم، الوقت، التفاصيل).
- **الاعتمادية**: كتابة ذرّية للملف (tmp + rename) وتراجع تلقائي عند فشل المعاملة.

## 3. البنية

```
bhb-market-app/
├── server.js              نقطة دخول الويب (JsonStore + HTTP)
├── lib/
│   ├── domain.js          منطق الأعمال والمتطلبات + كل المسارات (مشترك)
│   ├── http-app.js        طبقة HTTP: جلسات، CSRF، ثابت، أمان (مشتركة)
│   └── store-json.js      مخزن JSON معاملاتي
├── public/                الواجهة (HTML/CSS/JS بدون أي مكتبة خارجية)
├── desktop/               Electron + Realm (نفس الواجهة ومنطق الأعمال)
├── data/db.json           البيانات (تُنشأ تلقائياً مع بيانات تجريبية)
└── tests/smoke.js         اختبارات دخانية لواجهة API
```

**لماذا هذا التصميم؟** فصل `domain.js` عن التخزين يسمح بتشغيل نفس القواعد محلياً في
سطح المكتب (Realm) وعلى الخادم (JSON/قاعدة بيانات لاحقاً) دون ازدواج المنطق — وهو
العلاج المباشر لفجوة «ازدواجية الملفات» (GAP-13) في التطبيق القديم.

## 4. الاختبارات

```bash
node server.js &          # أو في نافذة أخرى
node tests/smoke.js
```

تغطي الاختبارات: الدخول والصلاحيات، CSRF، CRUD، حساب المجاميع (HT/VAT/Timbre)،
خصم المخزون وإرجاعه، الدفع الجزئي والكلي، التحويل من وصل إلى فاتورة دون خصم مزدوج،
والتقارير. النتيجة الحالية: **30/30 ✅**.

## 5. نسخة سطح المكتب (Electron + Realm)

```bash
cd desktop
npm install     # مرة واحدة (تحتاج إنترنت لتنزيل electron و realm)
npm start
```

- تعمل دون خادم أو إنترنت، والبيانات في مجلد بيانات المستخدم.
- إن تعذّر تثبيت `realm`، يعمل التطبيق تلقائياً بمخزن JSON محلي ويظهر تنبيه يشرح التفعيل.
- التفاصيل في [`desktop/README.md`](desktop/README.md).

---

## 6. ما بعد الإصدار الأول (خارطة الطريق)

الوحدات `FUT` في وثيقة المتطلبات: الدفعات الجزئية المتقدمة والآجال، المرتجعات
(إشعارات دائن)، عدة مستودعات/فروع، QR والفاتورة الإلكترونية، تطبيق نقطة بيع،
وصلاحية على مستوى الحقول (الأسعار/التخفيض).

## 7. ملاحظات أمنية للنشر

- شغّل خلف HTTPS (وكيل عكسي) وفعّل `Secure` على الكوكي (مطبّق تلقائياً عند TLS).
- بدّل كلمة سر `admin` فوراً، وأنشئ نسخة احتياطية دورية (شاشة الإعدادات).
- لا تشارك ملف `data/db.json` أو `bhb-market.realm`؛ فهما يحتويان كل البيانات.
